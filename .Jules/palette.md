## 2023-10-04 - Form Label Bindings
**Learning:** In forms across the app, `<input>` elements are sometimes nested directly inside `<label>` tags without `id` and `htmlFor` attributes. While this is valid HTML, using explicit bindings is a better practice for accessibility, ensuring that screen readers properly associate the label with the input.
**Action:** When working on form UX, check for and add explicit `id` and `htmlFor` attributes to form fields.
