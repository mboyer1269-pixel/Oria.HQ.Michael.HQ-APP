## 2024-03-24 - Interactive Component Focus States
**Learning:** Custom interactive elements (especially buttons built with complex Tailwind styling and SVG icons) in Cockpit dashboards frequently omitted `focus-visible` styling, making keyboard navigation invisible and inaccessible for power users.
**Action:** Establish a standard practice to always add `focus-visible:outline-none focus-visible:ring-2` with appropriate offset and color to custom buttons across the UI.
